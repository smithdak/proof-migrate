# Capability lifecycle

This directory is for reviewed, reusable capability artifacts—not client evidence.

- Deterministic work with stable inputs becomes code, a rule, or a mapping recipe.
- Contextual judgment or multi-tool work becomes a skill candidate only after at least three repeated traces and a measurable outcome exist.
- Authority-sensitive work becomes policy or a human decision, never an automatically promoted skill.
- Candidate discovery stays off the migration execution path. Known signatures use compiled exact routing with zero model calls.
- Automatic promotion is limited to read-only, non-lossy, non-production candidates that reproduce deterministically and pass the retained corpus.

Generated run-specific candidates belong in the isolated output bundle. Only generalized, client-safe, qualified artifacts may be proposed for this repository.
